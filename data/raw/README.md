# `data/raw/`

## What is here

`engagement_survey_2024.xlsx` — a **demo workbook**. Invented numbers, generated by
`scripts/make_demo_workbook.py` with a fixed seed, committed so the pipeline runs on a fresh
clone with no extra steps.

It is structurally identical to the client's file — sheet `results`, 22 columns, 42 rows
(8 category headers + 34 items), two items on a 1-10 scale, departments stored as deltas from the
company mean, an empty `manager` column — and numerically unrelated to it.

To regenerate it:

```bash
python scripts/make_demo_workbook.py --force   # or: make demo-data
```

## What is not here

The client's real *Employee Engagement Survey 2024* workbook. It is not redistributable and is
excluded from this repository, along with everything derived from it.

## Running on the real workbook

1. Place the supplied workbook at `data/raw/engagement_survey_2024.xlsx`, replacing the demo file.
2. Set `data.provenance: "real"` in `config/config.yaml`, so figures are badged REAL rather than
   DEMO.
3. `make pipeline`.

The analysis code is identical in both cases. `io.validate_raw_structure` checks the file's shape
on load and stops with a named error if a column or category header has changed, rather than
analysing a file it has misunderstood.
